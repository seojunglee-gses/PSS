# 단계별 채팅 시작 화면

## 변경 전 확인

다섯 계획 단계는 `pages/workspace/index.tsx`의 `renderChatPanel`/`handleSend`를 사용합니다. 문제 정의는 일반 빈 화면, 자료 분석은 한국어 안내, 계획안 평가는 영어 안내를 표시했습니다. 자료 분석·계획안 평가 안내는 실제 대화 앞에 화면에서만 붙였고 Firebase에는 저장하지 않았습니다. 최종안 결정의 기존 안내 설정은 채팅 패널이 렌더링되지 않아 보이지 않았습니다.

계획안 만들기는 별도 자동 생성 효과가 입장 직후 이미지 답변을 생성하고 Firebase에 저장했습니다. 이 효과는 제거했습니다. 이제 첫 질문을 보낼 때 기존 이미지 생성 API를 사용합니다. 초기 생성 입력의 기존 `recentDiscussion`에 첫 질문을 포함하고, 성공 시 기존 `alternativesInitialized` 요약 필드를 유지합니다. 이전에 저장된 자동 이미지 답변은 삭제하거나 필터링하지 않습니다.

## 공유 구조와 전송

- `lib/stage-chat-guides.ts`: 다섯 단계의 제목·설명·추천 질문 4개. 요청된 한국어 문구와 기존 언어 선택에 맞춘 영어·중국어 설정을 제공합니다.
- `components/chat/StageChatEmptyState.tsx`: 같은 가벼운 카드 구조로 안내와 질문 버튼을 표시합니다. 잠금/전송 중에는 비활성화합니다.
- `pages/workspace/index.tsx`: 해당 UID/사업/단계의 대화 조회가 끝나고 기록이 비었을 때만 안내를 표시합니다. 조회 중이나 기존 대화가 있을 때는 안내를 표시하지 않습니다. 최종안 결정의 기존 두 결과 영역 아래에도 같은 채팅 패널을 표시합니다.

추천 질문은 입력창에 복사하지 않고 `handleSend(question)`을 호출합니다. 수동 입력과 추천 질문 모두 기존 함수의 동기 `sendingRef` 잠금, 사용자 메시지 표시, 저장, API 요청, 답변 저장, 오류 처리와 잠금 해제를 사용합니다. 별도 전송 구현이나 API가 없습니다. 자료 분석의 `selectedSources`/`effectiveSources` 계산과 `+` 선택 컴포넌트는 그대로 사용합니다.

채팅 안내는 메시지 배열에 들어가지 않으며 저장되지 않습니다. 대화의 Firebase 스키마와 저장 경로는 바뀌지 않습니다. 기존 사용자 대화·이미지·근거 기록은 그대로 복원합니다. 빈 기록을 읽으면 안내가 다시 표시됩니다. 새 대화 삭제 기능은 추가하지 않았습니다. 모델/인증/논문 검색/근거 패널/단계 요약 및 단계 완료 처리는 유지합니다.

## 검증 결과

2026-10-05, 실제 화면 컴포넌트를 사용하는 Chromium 검증:

- 다섯 단계에서 제목·설명·질문 4개를 표시하고, 클릭 한 번으로 사용자 메시지와 기존 요청/답변 흐름으로 전환.
- 같은 버튼을 연속 두 번 눌러도 요청 1회, 사용자 기록 1개와 답변 1개. 새로고침하면 안내 없이 기존 대화를 복원.
- 자료 분석의 사례만/논문만/둘 다/명시적 선택 없는 기본 상태를 유지.
- 실패 시 질문을 유지하고 전송 잠금을 해제. 수동 입력 후 재전송 성공.
- 지연된 과거 대화 조회 중에는 안내를 숨기고, 기존 assistant-only 기록도 변경하지 않음.
- 빈 기록으로 돌아오면 안내 복원. 안내만 보는 동안 저장 요청 없음.
- 1440px 데스크톱/390px 모바일의 다섯 단계에서 읽기와 줄바꿈 확인, 가로 넘침 없음.

브라우저 검증은 Firebase 인증과 AI 응답, 대화 저장 경계에 검증용 구현을 사용했습니다. 운영 로그인/실제 AI 응답을 검증한 것은 아닙니다. 프로젝트 입장은 실제 프로젝트 API와 로컬 Firestore 에뮬레이터를 사용했습니다.

기존 연구·대화 저장·공간 분석 테스트 **32개 통과**. TypeScript 검사와 프로덕션 빌드 통과. 새 안내 컴포넌트/설정 파일은 ESLint 오류 없음. 기존 작업 공간에는 관련 없는 lint 오류가 남아 있으며 수정하지 않았습니다.

변경 파일: 위 세 구현 파일과 이 문서. 프로젝트 참여 저장 변경은 별도 커밋과 `project-membership.md`에 기록합니다.
