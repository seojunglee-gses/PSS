# 가좌 회복의 숲 검색 기준

이 프로젝트에만 적용하는 기준입니다. 사업구역은 인천 가좌1동 행정동 경계이며, 기본 장소 탐색은 가정로126번길 주변 500m와 가좌1동이 겹치는 범위입니다. 사업구역 전체를 요청하면 가좌1동 전체에서 찾습니다. 기존 업로드 자료와 Firebase 저장 내용은 변경하지 않습니다.

## 출처

경계는 통계청 SGIS 행정동 경계(공공누리 제1유형)를 가공한 [vuski/admdongkor 2026-10-01 자료](https://github.com/vuski/admdongkor/tree/master/ver20261001)에서 인천 가좌1동 한 객체를 추출했습니다. 좌표는 변경하지 않았으며 이름·별칭·출처 속성을 추가했습니다. 원 자료의 행정구 이름은 서해구이며, 표시용 이름은 사용자가 지정한 인천 가좌1동입니다. 가공물은 CC BY 4.0이며 상세 출처와 조건은 LICENSE-DATA.txt를 따릅니다.

도로는 [OpenStreetMap](https://www.openstreetmap.org/copyright)의 동일 지역 지도 데이터에서 이름이 일치하는 가정로126번길 way를 추출했습니다. 좌표는 원본 그대로이고 출처 URL·별칭을 보존합니다. © OpenStreetMap contributors, ODbL 1.0. 독립된 도로 데이터셋의 배포 조건은 ODbL을 따릅니다. 취득일: 2026-11-09.

기준 레이어는 지도와 서버 검색에서 같은 설정을 사용합니다. Kakao에는 이 범위의 사각형 검색 창을 보내며, 기존 GIS 필터가 범위 밖 후보를 제외합니다. Kakao 결과는 제한된 탐색 후보이므로 전체 점포 수·밀도·시설 충분성을 뜻하지 않습니다.
